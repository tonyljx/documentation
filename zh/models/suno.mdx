## Suno

Suno V6 是 Suno 的音乐模型。在 Wizzx 上它使用 `suno` model key，并以**音乐动作**的形式提供：`POST /api/v1/music/{action}` 可以创作歌曲与音效、基于已有曲目继续创作、编辑曲目，以及分析或导出曲目。每个动作都是一个异步任务，通过 `POST /api/v1/task/status` 查询，每次调用计费一次。

`POST /api/v1/task/submit/suno` 仍然可用，等同于 `generate` 动作。

每个动作的字段、模式规则与错误码见 [提交音乐动作](/zh/api-reference/endpoint/submit-music)。

### 能做什么

| 分组 | 动作 |
| --- | --- |
| 创作 | `generate`（根据描述或自有歌词生成歌曲）、`inspo`（基于 1–4 个参考音频 URL）、`sounds`（音效与循环）、`lyrics`、`upsample-tags`（增强风格描述）、`upload`、`upload-cover`、`upload-extend`、`create-model`（用 6–24 首歌曲创建自定义模型）、`create-voice` |
| 基于已有曲目 | `extend`、`concat`、`cover`、`remaster`、`add-vocals`、`add-instrumental`、`add-stem`、`mashup`、`sample`、`persona` |
| 编辑 | `replace-section`、`remove-section`、`crop`、`fade-in`、`fade-out`、`adjust-speed`、`stems`、`stems-all` |
| 分析与导出 | `midi`、`aligned-lyrics`、`bpm`、`music-video`、`download`（MP3、M4A、WAV） |

### 生成歌曲

`generate` 通过 `custom` 选择模式：

- **灵感模式**（`custom: false`，默认）：`prompt` 为歌曲描述，最多 3,000 个字符。
- **自定义模式**（`custom: true`）：`prompt` 填写歌词（最多 5,000 个字符），可选 `title`、`style`、`negative_tags`、`auto_lyrics`、`persona_task_id`、`max_mode` 与 `duration`。

| 参数 | 必填 | 可接受值 |
| --- | --- | --- |
| `prompt` | 视模式而定 | 灵感模式：必填，最多 3,000 个字符。自定义模式：歌词，最多 5,000 个字符；除非 `instrumental` 为 `true`，否则必填 |
| `custom` | 否 | `false`（默认）或 `true` |
| `instrumental` | 否 | `false`（默认），传 `true` 生成无人声纯音乐；自定义纯音乐需要 `prompt` 或 `style` |
| `version` | 否 | `v6`（默认）、`v6-wild` 或 `v6-mini`（不区分大小写），价格相同 |
| `custom_model_task_id` | 否 | 你已完成的 `create-model` 任务的 `task_id`，用于替代 `version`；不能与 `version` 或 `persona_task_id` 同时使用 |
| `persona_task_id` | 否 | 仅自定义模式。你已完成的 `persona` 任务的 `task_id` |
| `title` | 否 | 仅自定义模式，最多 80 个字符 |
| `style` | 否 | 仅自定义模式，风格标签，最多 1,000 个字符 |
| `negative_tags` | 否 | 仅自定义模式，需要避开的风格，最多 1,000 个字符 |
| `style_weight`、`weirdness`、`audio_weight` | 否 | 0 到 1 之间的数字 |
| `vocal_gender` | 否 | `Male` 或 `Female`；不能与 `instrumental: true` 同时使用 |
| `auto_lyrics` | 否 | 仅自定义模式，`true` 或 `false` |
| `variety` | 否 | `off`、`normal`、`high`、`extra` 或 `max` |
| `max_mode` | 否 | 仅自定义模式；更高质量，价格翻倍 |
| `audio_format` | 否 | `mp3`、`m4a` 或 `wav` |
| `duration` | 否 | 仅自定义模式；目标时长 10–360 秒，实际时长可能不同；不影响价格 |

文本长度按 Unicode 字符计算。传入动作不接受的字段（包括在灵感模式下传入仅限自定义模式的字段）会返回 HTTP 422。

灵感模式：

```json
{
  "prompt": "深夜城市 lo-fi 钢琴，伴着雨声",
  "instrumental": true
}
```

自定义模式：

```json
{
  "custom": true,
  "prompt": "[Verse]\n雨夜里霓虹闪烁的街道",
  "title": "Midnight Drive",
  "style": "synthwave, female vocal, cinematic",
  "negative_tags": "metal, screaming",
  "vocal_gender": "Female",
  "duration": 180
}
```

提交到 `POST /api/v1/music/generate`（或等价的 `POST /api/v1/task/submit/suno`）。保存响应中的 `data.task_id`，再通过 `/api/v1/task/status` 查询。生成通常需要 30–120 秒。

### 结果

任务成功后，`result_urls` 列出所有生成曲目的 URL，`result.tracks` 返回每首曲目的详细信息：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "6f0c1c52-2a4b-4d53-9a5e-3c0f2f7d9e11",
    "status": "SUCCEEDED",
    "result_urls": [
      "https://cdn.wizzx.ai/audio/2026/10/15/track-1.mp3",
      "https://cdn.wizzx.ai/audio/2026/10/15/track-2.mp3"
    ],
    "error": "",
    "credits_deducted": 60,
    "result": {
      "tracks": [
        {
          "index": 1,
          "audio_url": "https://cdn.wizzx.ai/audio/2026/10/15/track-1.mp3",
          "image_url": "https://cdn.wizzx.ai/images/2026/10/15/cover-1.jpg",

          "duration": 119.8
        },
        {
          "index": 2,
          "audio_url": "https://cdn.wizzx.ai/audio/2026/10/15/track-2.mp3",
```

不要假定一定是两首，请遍历 `result.tracks` 或 `result_urls`。其他动作会在 `result` 中返回歌词、BPM、MIDI、文件、视频或 ID，详见 [任务状态中的音乐结果](/zh/api-reference/endpoint/task-status)。

### 基于曲目继续创作

用曲目所在任务的 `task_id`，并把曲目的 `index` 作为 `audio_index`，即可引用已完成的曲目。例如用 `POST /api/v1/music/extend` 从 1:30 处续写第 2 首：

```json
{
  "task_id": "6f0c1c52-2a4b-4d53-9a5e-3c0f2f7d9e11",
  "audio_index": 2,
  "continue_at": 90,
  "prompt": "[Bridge]\n城市在身后渐渐远去"
}
```

之后用 `concat` 把续写拼接为完整歌曲。只能引用你自己的、状态为 `SUCCEEDED` 的 Suno 任务。`add-vocals`、`add-instrumental` 与 `sample` 需要 `upload` 任务作为来源，`concat` 需要 `extend` 或 `upload-extend` 任务。详见 [提交音乐动作](/zh/api-reference/endpoint/submit-music) 中的「引用已有任务」。

### 计费

每次调用对整个任务计费一次，与返回多少首曲目无关。`version` 与 `duration` 不影响价格。

| 动作 | 每次调用积分 | 开启 `max_mode: true` |
| --- | --- | --- |
| `generate`、`extend`、`cover`、`upload-cover`、`upload-extend`、`add-vocals`、`add-instrumental`、`add-stem`、`mashup`、`sample`、`replace-section` | 60 | 120 |
| `inspo` | 131 | 262 |
| `remaster`、`midi` | 60 | – |
| `stems` | 193 | – |
| `stems-all` | 462 | – |
| `create-model` | 1,847 | – |
| `adjust-speed` | 47 | – |
| `create-voice` | 31 | – |
| `sounds` | 19 | – |
| `lyrics`、`crop`、`fade-in`、`fade-out`、`remove-section` | 16 | – |
| `upload`、`persona`、`concat`、`music-video`、`upsample-tags` | 8 | – |
| `download` | 3 | – |
| `aligned-lyrics`、`bpm` | 2 | – |

<Note>
  在有模式开关的动作上，`max_mode` 需要自定义模式。失败的任务会退回积分。仍应以 `/pricing` 返回值为当前事实依据。
</Note>

机器可读 Schema 请查看 [提交音乐动作](/zh/api-reference/endpoint/submit-music)；旧入口见 [提交 Suno 任务](/zh/api-reference/endpoint/submit-suno)。
