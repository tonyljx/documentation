## 概览

- 模型：Nano Banana 2 Lite（`nano-banana-2-lite`），Google 出品；支持文生图与图生图，最多 10 张参考图。
- 简单可预测：固定 24 积分/张，无分辨率与输出格式选项。
- 画幅：从 `1:1` 到 `21:9` 共 14 种选项，外加 `auto`（默认）。
- 异步接口：提交 `POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-2-lite`，查询 `POST https://api.wizzx.ai/api/v1/task/status`。

## 认证

```bash
Authorization: Bearer <your_api_key>
```

## 提交任务

接口：`POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-2-lite`，`Content-Type: application/json`

| 字段 | 类型 | 必填 | 默认/限制 | 说明 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | ≤ 20000 字符 | 文本提示词 |
| `image_urls` | array&lt;string&gt; | 否 | 最多 10 张 | 参考图 URL 列表 |
| `aspect_ratio` | string | 否 | 默认 `auto` | `1:1`、`1:4`、`1:8`、`2:3`、`3:2`、`3:4`、`4:1`、`4:3`、`4:5`、`5:4`、`8:1`、`9:16`、`16:9`、`21:9`、`auto` |

<Note>
  需要 `1K/2K/4K` 分辨率控制或 `png` 输出？请使用 [Nano Banana 2](/zh/models/nano-banana-2)。
</Note>

### 请求示例（文生图）

```bash
curl -X POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-2-lite \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "戴墨镜的可爱猫咪，卡通风格",
    "aspect_ratio": "1:1"
  }'
```

### 请求示例（图生图）

```bash
curl -X POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-2-lite \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "把这张照片转成水彩风格",
    "image_urls": [
      "https://example.com/photo.jpg"
    ]
  }'
```

## 查询状态

接口：`POST https://api.wizzx.ai/api/v1/task/status`

```json
{
  "task_id": "4bbbc9e0-8de8-4f35-a31e-8596c1a6d18a"
}
```

客户端可见状态：`PENDING`、`QUEUED`、`PROCESSING`、`REVIEW_REQUIRED`、`SUCCEEDED`、`FAILED`。详见任务状态 API 参考。

## 计费

固定 **24 积分/张**（1000 积分 = $1），与参数无关。

## 最佳实践

- 适合大批量、成本敏感的生成场景与快速草稿。
- 需要 2K/4K 输出或 PNG 格式时，升级到 [Nano Banana 2](/zh/models/nano-banana-2)。
- 参考图保持 1-3 张，结果最可控。
