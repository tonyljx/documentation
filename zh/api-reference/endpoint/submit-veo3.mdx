## 提交任务

`prompt` 和 `type` 必填。文生视频使用 `text-to-video` 且不传图片；首尾帧使用 `image-to-video` 并传一至两张图；参考图视频使用 `reference-to-video` 并传一至三张图。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/veo3 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "一只狗在夜晚的霓虹城市中奔跑",
    "type": "text-to-video",
    "duration": 6,
    "resolution": "720p",
    "model": "veo3_lite",
    "aspect_ratio": "16:9"
  }'
```

<Note>
  当前公开 `veo3_fast`、`veo3_lite` 与 `veo3_quality`，分辨率可选 `720p`、`1080p`、`4k`。档位与分辨率决定每个视频的固定扣费，时长不影响价格。Fast 与 Lite 支持 `4`、`6`、`8` 秒；Quality 仅支持 `6` 或 `8` 秒，且不支持参考图视频。参考图视频必须使用 8 秒。保存 `data.task_id` 后查询 `/api/v1/task/status`。
</Note>
