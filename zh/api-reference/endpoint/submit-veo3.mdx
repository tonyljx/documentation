## 提交任务

`prompt` 和 `type` 必填。文生视频使用 `text-to-video` 且不传图片；首尾帧使用 `image-to-video` 并传一至两张图；参考图视频使用 `reference-to-video` 并传一至三张图。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/veo3 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "一只狗在夜晚的霓虹城市中奔跑",
    "type": "text-to-video",
    "duration": 6,
    "resolution": "720p",
    "model": "veo3_fast",
    "aspect_ratio": "16:9"
  }'
```

<Note>
  当前唯一公开档位是 `veo3_fast` 和 `720p`。时长可选 `4`、`6`、`8` 秒。参考图视频必须使用 `16:9` 和 8 秒。保存 `data.task_id` 后查询 `/api/v1/task/status`。
</Note>
