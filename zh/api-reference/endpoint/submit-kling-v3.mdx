## 提交任务

`prompt` 与 `type` 必填。`image-to-video` 传 1 个公网 HTTP(S) 图片 URL（首帧）或 2 个（首帧和尾帧）；`text-to-video` 不可传 `image_urls`。`resolution` 为 `720p`（默认）或 `1080p`，`duration` 为 3–15 秒（默认 5）。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/kling-v3 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "雨夜东京十字路口，霓虹灯倒映在湿润地面上",
    "type": "text-to-video",
    "resolution": "1080p",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

网关按秒计费：720p = 130（有声 194）、1080p = 173（有声 259）积分/秒。具体积分以 `/pricing` 为准。
