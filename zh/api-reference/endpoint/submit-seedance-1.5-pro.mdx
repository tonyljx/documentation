## 提交任务

`prompt` 和 `type` 必填。`image-to-video` 需要一至两个公网 HTTP(S) 图片 URL，用于首帧或首尾帧控制；`text-to-video` 必须省略 `image_urls`。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/seedance-1.5-pro \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "一只猫在弹钢琴，伴随着轻柔的爵士乐",
    "type": "text-to-video",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true
  }'
```

<Warning>
  当前 HTTP 合同只接受 `4`–`12` 秒和显式 `720p`。模型层虽然计划支持 `duration=-1` 和 `480p`，但公共网关 binding 目前会拒绝这两个值。`generate_audio` 默认 `true`，后端固定使用 24fps。
</Warning>
