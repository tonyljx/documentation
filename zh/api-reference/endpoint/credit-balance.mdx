## 查询积分余额

使用与任务提交相同的 Wizzx API Key。

```bash
curl --fail-with-body --silent --show-error \
  https://api.wizzx.ai/api/v1/credits/balance \
  -H "Authorization: Bearer <api_key>"
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "balance": 15200,
    "free_credits": 200,
    "paid_credits": 15000,
    "usd_equivalent": 15.2
  },
  "request_id": "2c8d3b9e-4f1a-4c62-9e77-8a1b5c4d2e90"
}
```

- `data.balance` 为当前可用总积分（`free_credits + paid_credits`）。
- `data.usd_equivalent` 按固定汇率 `1,000 积分 = $1.00 美元` 折算。
- 查询余额不会预留积分；只有在任务提交通过校验并被接受时才会原子预留积分。
