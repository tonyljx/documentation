## 提交任务

`prompt` 必填。图片生成时省略 `image_urls`；图片编辑时最多传入 16 个 HTTP(S) URL 或 base64 data URI（JPEG、PNG、WebP）。`version` 可选 `flare`（默认）或 `sunburst`。每个被接受的请求生成一张图片。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/gpt-image-2.5 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "深色桌面上的橙色机械键盘",
    "version": "flare",
    "aspect_ratio": "16:9",
    "resolution": "2K"
  }'
```

网关按 `resolution` 每张计费：1K = 13、2K = 21、4K = 32 积分。`version`、`aspect_ratio` 与参考图不影响价格。具体积分以 `/pricing` 为准。
