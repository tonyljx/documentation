## 提交任务

`prompt` 与 `type` 必填。`image-to-video` 传 1–2 个公网 HTTP(S) 图片 URL（首帧、尾帧）；`reference-to-video` 传 1–7 张参考图，提示词中可用 `<<<image_1>>>` … `<<<image_N>>>` 引用；`text-to-video` 不可传 `image_urls`。

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/kling-v3-omni \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "<<<image_1>>> 中的角色走进 <<<image_2>>> 中的场景",
    "type": "reference-to-video",
    "image_urls": [
      "https://example.com/character.jpg",
      "https://example.com/scene.jpg"
    ],
    "resolution": "720p",
    "duration": 5
  }'
```

网关按秒计费：720p = 130（有声 173）、1080p = 173（有声 216）积分/秒，参考图不另收费。具体积分以 `/pricing` 为准。
