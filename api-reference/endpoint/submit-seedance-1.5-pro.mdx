## Submit task

`prompt` and `type` are required. `image-to-video` requires one or two public HTTP(S) image URLs for first-frame or first/last-frame control. `text-to-video` must omit `image_urls`.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/seedance-1.5-pro \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A cat playing piano with soft jazz music",
    "type": "text-to-video",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true
  }'
```

<Warning>
  The current HTTP contract accepts duration `4`–`12` and explicit resolution `720p`. Although the model layer intends to support `duration=-1` and `480p`, the shared gateway binding currently rejects both. `generate_audio` defaults to `true`; fixed 24fps is used.
</Warning>
