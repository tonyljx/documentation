## Submit task

`prompt` is required (at most 800 characters). Omit `image_urls` for generation, or provide 1–3 public HTTP(S) URLs for editing; base64 is rejected. `resolution` is `1K` (default) or `2K`. Each request produces one image.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/qwen-image-2.0 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A minimalist poster with the headline SUMMER SALE in bold serif type",
    "aspect_ratio": "3:4",
    "resolution": "2K"
  }'
```

The gateway charges 31 credits per image; 1K and 2K cost the same. Read `/pricing` for the current amount.
