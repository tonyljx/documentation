## Submit task

This endpoint is identical to [`POST /api/v1/music/generate`](/api-reference/endpoint/submit-music) and remains supported. Use [music actions](/api-reference/endpoint/submit-music) for new integrations: they cover generation plus extending, covering, editing, stem separation, analysis, and downloads.

In inspiration mode (`custom: false`, default) `prompt` is a required song description. In custom mode (`custom: true`) `prompt` holds the lyrics and you can add `title`, `style`, `negative_tags`, `auto_lyrics`, `persona_task_id`, `max_mode`, and `duration`. Fields that `generate` does not accept return HTTP 422. One request usually returns two tracks; when the task succeeds, read all of them from `result_urls` or `result.tracks`.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/suno \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "Late-night city lo-fi piano with the sound of rain",
    "instrumental": true
  }'
```

The gateway charges 60 credits per request, or 120 credits with `max_mode: true` (custom mode only). The price covers every returned track. Read `/pricing` for the current amount.
