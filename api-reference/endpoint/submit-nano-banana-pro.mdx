## Submit task

- Header: `Authorization: Bearer <your_api_key>`.
- Required: `prompt`. Optional: `image_urls` (max 8, 30MB each), `aspect_ratio`, `resolution`, `output_format`.
- Async `task_id` and `credits_deducted`; poll `/api/v1/task/status`.
- **Breaking:** `image_input` deprecated; use `image_urls`.

```bash
curl -X POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-pro \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A beautiful sunset over the ocean",
    "image_urls": [
      "https://example.com/reference1.jpg",
      "https://example.com/reference2.jpg"
    ],
    "aspect_ratio": "16:9",
    "resolution": "2K",
    "output_format": "png"
  }'
```

<Note>
  Aspect ratio defaults to `1:1`; the runtime resolution default is `1K`; output format defaults to `png`. Accepted output aliases are `png`, `jpg`, and `jpeg`. Current tiers are 1K=`108`, 2K=`108`, and 4K=`144` credits; always re-read `/pricing` before submission.
</Note>
