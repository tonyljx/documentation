## Submit task

`prompt` is required. Omit `image_urls` for text-to-video, send exactly 1 public HTTP(S) image for first-frame image-to-video, or send 1 or 3 images for reference-to-video. `type` is inferred from the image count when omitted (1 image → image-to-video, 3 → reference-to-video).

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/gemini-omni-flash \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A paper lantern drifts over a quiet river at dusk",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 6
  }'
```

The gateway charges a fixed price per video: 720p and 1080p = 481 / 577 / 674 / 770 credits and 4k = 1,443 / 1,539 / 1,635 / 1,731 credits for 4 / 6 / 8 / 10 seconds. Read `/pricing` for the current amount.
