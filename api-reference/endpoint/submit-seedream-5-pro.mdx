## Submit task

`prompt` is required. Omit `image_urls` for generation, or provide exactly one HTTP(S) URL or base64 data URI (JPEG, PNG, or WebP) for editing. `resolution` accepts `1K` (default), `1.5K`, or `2K`; `output_format` accepts `jpeg` (default) or `png`. Each accepted request produces one image.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/seedream-5-pro \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A bilingual coffee shop menu board with clean typography",
    "aspect_ratio": "3:4",
    "resolution": "1.5K",
    "output_format": "png"
  }'
```

The gateway charges per image by `resolution`: 1K = 44, 1.5K = 44, 2K = 89 credits. `aspect_ratio`, `output_format`, and the reference image do not change the price. Read `/pricing` for the current amount.
