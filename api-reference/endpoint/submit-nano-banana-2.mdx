## Submit task

`prompt` is required. Omit `image_urls` for text-to-image, or provide up to 14 public HTTP(S) image URLs for editing and reference generation.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/nano-banana-2 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A clean isometric city in warm afternoon light",
    "aspect_ratio": "16:9",
    "resolution": "1K",
    "output_format": "jpg"
  }'
```

If omitted, `aspect_ratio` defaults to `auto`, `resolution` to `1K`, and `output_format` to `jpg`. Read `/pricing` before submission for current resolution tiers.
