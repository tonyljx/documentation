## Submit task

`prompt` and `type` are required. Use `text-to-video` without images, `image-to-video` with one or two frame images, or `reference-to-video` with one to three reference images.

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://api.wizzx.ai/api/v1/task/submit/veo3 \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  --data '{
    "prompt": "A dog running through a neon city at night",
    "type": "text-to-video",
    "duration": 6,
    "resolution": "720p",
    "model": "veo3_fast",
    "aspect_ratio": "16:9"
  }'
```

<Note>
  The only public model tier is `veo3_fast` at `720p`. Duration is `4`, `6`, or `8` seconds. Reference-to-video requires `16:9` and 8 seconds. Save `data.task_id` and poll `/api/v1/task/status`.
</Note>
