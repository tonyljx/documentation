## Qwen Image 2.0

Qwen Image 2.0 is Alibaba Qwen's image generation and editing model. Wizzx offers two model keys with the same request fields:

| Model key | Best for |
| --- | --- |
| `qwen-image-2.0` | Balanced quality and speed |
| `qwen-image-2.0-pro` | Stronger text rendering and more refined realistic textures |

Omit `image_urls` for text-to-image, or provide up to 3 reference images for image-to-image editing.

### Request parameters

| Parameter | Required | Accepted values |
| --- | --- | --- |
| `prompt` | Yes | Non-blank text, at most 800 characters |
| `negative_prompt` | No | At most 500 characters |
| `image_urls` | No | 1–3 public HTTP(S) URLs (JPG, JPEG, PNG, or WebP). Base64 and data URIs are rejected |
| `aspect_ratio` | No | `1:1` (default), `4:3`, `3:4`, `16:9`, `9:16`, `3:2`, `2:3` |
| `resolution` | No | `1K` (default) or `2K` (case-insensitive) |

Each request produces one image. At `1:1` the output is 1024 × 1024 (1K) or 2048 × 2048 (2K).

```json
{
  "prompt": "A minimalist poster with the headline \"SUMMER SALE\" in bold serif type",
  "negative_prompt": "blurry, watermark",
  "aspect_ratio": "3:4",
  "resolution": "2K"
}
```

Submit to `POST /api/v1/task/submit/qwen-image-2.0` or `POST /api/v1/task/submit/qwen-image-2.0-pro`. Save the returned `data.task_id` and poll `/api/v1/task/status`.

### Pricing

| Model | Credits per image |
| --- | --- |
| Qwen Image 2.0 | 31 |
| Qwen Image 2.0 Pro | 74 |

<Note>
  1K and 2K cost the same. Aspect ratio and reference images do not change the price. `/pricing` remains the current source of truth.
</Note>
