## Seedance 2.0 Mini

Seedance 2.0 Mini belongs to ByteDance's Seedance 2.0 video family. Use `seedance-2.0-mini` for text-to-video or image-to-video at 480p or 720p, from 4 to 15 seconds. An audio track is generated by default at no extra charge.

- `text-to-video`: omit `image_urls`.
- `image-to-video`: 1 image sets the first frame; 2 images set the first and last frame.

### Request parameters

| Parameter | Required | Accepted values |
| --- | --- | --- |
| `prompt` | Yes | Non-blank text, at most 4,000 characters |
| `type` | Yes | `text-to-video` or `image-to-video` |
| `image_urls` | For `image-to-video` | 1–2 public HTTP(S) URLs (first frame, last frame). Not allowed for `text-to-video` |
| `resolution` | No | `480p` or `720p` (default) |
| `duration` | No | Integer seconds from `4` to `15`, default `5` |
| `aspect_ratio` | No | `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive` (`auto` is an alias). Defaults to `16:9` for text-to-video and `adaptive` for image-to-video |
| `generate_audio` | No | `true` (default) or `false`. Does not change the price |
| `seed` | No | `-1` (random) or `0`–`4294967295` |

Each request produces one video. Reference video, reference audio, 1080p, and 4K are not offered.

```json
{
  "prompt": "Transition from a sunny street to the same street at night",
  "type": "image-to-video",
  "image_urls": [
    "https://example.com/day.jpg",
    "https://example.com/night.jpg"
  ],
  "resolution": "480p",
  "duration": 8
}
```

Submit to `POST /api/v1/task/submit/seedance-2.0-mini`. Save the returned `data.task_id` and poll `/api/v1/task/status`.

### Pricing

| Resolution | Credits per second |
| --- | --- |
| 480p | 21 |
| 720p | 44 |

<Note>
  Example: a 5-second 720p video costs 44 × 5 = 220 credits, with or without audio. `/pricing` remains the current source of truth.
</Note>

See the [Seedance 2.0 Mini API reference](/api-reference/endpoint/submit-seedance-2-0-mini) for the machine-readable Schema.
